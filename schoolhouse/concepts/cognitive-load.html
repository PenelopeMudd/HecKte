Cognitive Load

The demand on working memory at any given moment — and the difference between load that teaches and load that just costs.

Cognitive load theory distinguishes between extraneous load and germane load. Extraneous load is caused by factors outside the content itself: unclear instructions, uncertain expectations, environmental noise, procedural confusion. Germane load is what the lesson is actually asking the student to do. When extraneous load is high, germane load gets crowded out — the student is spending cognitive resources navigating the room rather than thinking about the content.

Standard 5 is substantially about managing extraneous load. Routines that run automatically, transitions that don’t require renegotiation, visual supports that offload procedural memory, expectations that are known and held: each of these reduces the friction that competes with thinking. The goal isn’t a frictionless classroom — it’s a classroom where the friction that remains is the friction of learning.
