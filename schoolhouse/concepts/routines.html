Routines

Repeated procedures that eventually run themselves — and the working memory they free once they do.

A routine is only a routine once it’s automatic. Until a procedure has been practiced enough to run from memory, it costs working memory to execute — exactly the resource it’s supposed to free. Teachers often install routines once and maintain them by repetition, but the repetition that builds automaticity is practice before the pressure, not correction during it.

The architecture matters: a routine that’s visible, predictable, and rehearsed until it runs without narration frees cognitive space for the content of the lesson. That’s the argument for investing time in them at the start of the year. The payoff is every other day.
