Transitions

The move between activities — where instructional time leaks, and where classroom tone is quietly set.

Transition time feels like dead time — gaps between the real work — so it gets treated as logistics rather than instruction. But a transition is a procedure, and like any procedure it has to be taught before it can be run. An untaught transition relies on every student assembling the next step on the spot, simultaneously, with no shared model, which is why most of the instructional time that leaks, leaks here.

The cost is dual: the time itself is lost, and the behavioral residue from an unmanaged transition is the first thing the next activity has to overcome. A class that can move cleanly is a class whose attention is available for what comes next.
