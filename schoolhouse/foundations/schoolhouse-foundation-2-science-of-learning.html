Science of Learning Basics

What cognitive science has established about how people learn — and why it matters for classroom design.

Working memory is the bottleneck

Learning requires new information to be held in working memory long enough to connect with what’s already stored. The problem: working memory is small. It holds roughly four chunks at a time, and it fatigues.

This isn’t a flaw in students — it’s architecture. It’s the same for every brain. A classroom that overloads working memory produces the appearance of inattention, off-task behavior, or confusion that looks like not caring. Often it’s just a cognitive system running at capacity on the wrong things.

“If nothing has been altered in long-term memory, nothing has been learned.”
Kirschner, Sweller & Clark, 2006

Extraneous load is the enemy

Cognitive load theory distinguishes between intrinsic load (the difficulty of the content itself), germane load (the work of connecting new information to prior knowledge), and extraneous load (cognitive effort caused by how the environment or instruction is designed — not by the content).

Extraneous load is what a teacher can actually reduce. A chaotic transition spends working memory on navigation. Unclear instructions spend it on parsing. A physical layout that requires students to interrupt the teacher to get materials spends it on logistics. All of that load comes out of the same limited pool the student needs for thinking about the content.

Classroom management, viewed through this lens, is largely extraneous load reduction.

Retrieval and spacing

The most durable finding in memory research: the act of retrieving information strengthens the memory more than re-reading or re-exposing does. Practice that requires retrieval — answering questions, writing from memory, explaining to someone else — outperforms passive review.

Spacing matters too. Information reviewed after a delay is retained longer than information reviewed immediately. This has implications for how content is sequenced across a unit and across a year, not just a single lesson.

Practical upshot: An exit ticket at the end of class produces more learning than re-reading notes. A warm-up that retrieves last week’s content produces more retention than starting fresh each day.

Prior knowledge is the scaffold

New information is only meaningful when it can connect to something already stored. A student who has no hook for new content — no analogy, no experience, no prior concept to attach it to — holds it in working memory without a place to put it, and it doesn’t stick.

This is why good teaching starts with activating prior knowledge, not because it’s warm and welcoming (though it is), but because the brain needs the scaffold before it can load the content.

Feedback closes the loop

Learning is a feedback loop: the student does something, gets information about how close they were to the target, and adjusts. When feedback is delayed, vague, or only evaluative (“good job” / “try again”), the loop doesn’t close. The student knows something happened but not what to change.

The most useful feedback is specific, targets the work rather than the person, and arrives while the student can still act on it.
